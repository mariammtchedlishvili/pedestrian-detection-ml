ქვეითების აღმოჩენის სისტემა (Pedestrian Detection — End-to-End ML Project)

პროექტი წარმოადგენს Computer Vision-ზე დაფუძნებულ Machine Learning სისტემას, რომელიც გამოსახულებებზე პოულობს ქვეითებს (Object Detection), სვამს მათ მართკუთხედ ჩარჩოებში (Bounding Boxes) და აბრუნებს თითოეული ობიექტის კოორდინატებსა და ალბათობას (Confidence Score).

პროექტი მოიცავს სრულ სამუშაო პროცესს: მონაცემთა შესწავლასა და მომზადებას (EDA, Data Augmentation), წინასწარ გაწვრთნილი მოდელების ადაპტაციას (Fine-Tuning), არქიტექტურების შედარებით ექსპერიმენტებს, შეცდომების ანალიზს (Error Analysis), მოდელის ოპტიმიზაციას (Quantization / Mixed Precision) და ინტერაქციულ ვებ-აპლიკაციას.

პროექტში შედარდა Faster R-CNN-ის ორი ვარიანტი თანაბარ პირობებში (5 ეპოქა, SGD ოპტიმიზატორი lr=0.005, momentum=0.9, weight_decay=0.0005, StepLR scheduler, Train/Val გაყოფა 136/34 სურათი):

4. ტექნიკური ანგარიში

1. რა პრობლემას წყვეტს პროექტი?

პროექტი წყვეტს ქუჩისა და გარე კამერების სურათებზე ქვეითების ავტომატური აღმოჩენისა და ლოკალიზაციის (Pedestrian Detection) ამოცანას. მსგავსი სისტემები გამოიყენება უსაფრთხოების მონიტორინგში, ჭკვიანი ქალაქის ინფრასტრუქტურაში, ნაკადების დათვლასა და მართვადი ტრანსპორტის დამხმარე სისტემებში.

2. რატომ შეარჩიეთ კონკრეტული მონაცემები, მოდელი და მიდგომა?

მონაცემთა ნაკრები: შეირჩა Penn-Fudan Pedestrian Dataset (170 სურათი, 345 მონიშნული ქვეითი, საშუალოდ ~2.03 ქვეითი თითო ფოტოზე). ნაკრები შეიცავს მკაფიო პიქსელურ ნიღბებს (Masks), საიდანაც ზუსტად გამოითვლება Bounding Box კოორდინატები. მისი კომპაქტური მოცულობა საშუალებას იძლევა უფასო გამოთვლით რესურსებზე (Google Colab T4 GPU) სწრაფად ჩატარდეს რამდენიმე სრულფასოვანი ექსპერიმენტი.

მოდელი და მიდგომა: მცირე მოცულობის მონაცემებზე ნულიდან გაწვრთნა იწვევს გადამეტებულ დასწავლას (Overfitting). ამიტომ გამოყენებულ იქნა Transfer Learning (Fine-Tuning): ავიღეთ COCO ნაკრებზე წინასწარ გაწვრთნილი Faster R-CNN არქიტექტურა Feature Pyramid Network (FPN) დაბოლოებით, რომელიც ეფექტურად პოულობს სხვადასხვა მასშტაბის ობიექტებს, და შევცვალეთ მისი კლასიფიკატორი (FastRCNNPredictor) 2 კლასზე (0 — ფონი, 1 — ქვეითი).

3. რა ექსპერიმენტები ჩაატარეთ და რა შედეგები მიიღეთ?

Data Augmentation: სასწავლო ნაკრებზე დაემატა შემთხვევითი ჰორიზონტალური შებრუნება (Horizontal Flip 50% ალბათობით) შესაბამისი Bounding Box კოორდინატების ტრანსფორმაციით.

Backbone-ების შედარება: შედარდა MobileNetV3-Large-FPN და ResNet50-FPN. ResNet50-FPN-მა სწრაფად შეამცირა სწავლის დანაკარგი (Loss) და სავალიდაციო ნაკრებზე მიაღწია F1 = 0.9068-სა და Mean IoU = 0.8948-ს.

ოპტიმიზაციის ექსპერიმენტი: შედარდა FP32, INT8 და FP16 რეჟიმები. FP16-მა მოგვცა საუკეთესო ბალანსი ზომას, სისწრაფესა და სიზუსტეს შორის.

4. რა პრობლემებს წააწყდით და როგორ გადაჭერით?

ანოტაციების ამოღება ნიღბებიდან: Penn-Fudan ნაკრებში ქვეითები მოცემულია პიქსელური ნიღბების სახით, სადაც თითოეულ ადამიანს თავისი უნიკალური მთელი რიცხვი (ID > 0) შეესაბამება. დაიწერა კოორდინატების გარდამქმნელი ლოგიკა (np.where), რომელიც თითოეული ID-ისთვის პოულობს მინიმალურ და მაქსიმალურ X/Y წერტილებს და აგებს მართკუთხედ ჩარჩოებს.

ჩარჩოების აუგმენტაცია: სურათის სარკისებურად შებრუნებისას მხოლოდ გამოსახულების შეტრიალება არღვევს ჩარჩოების მდებარეობას. პრობლემა გადაიჭრა X კოორდინატების სინქრონული გადათვლით (boxes[:, [0, 2]] = width - boxes[:, [2, 0]]).

სხვადასხვა რაოდენობის ობიექტები სურათებზე: სტანდარტული PyTorch DataLoader ვერ აერთიანებს ტენზორებს, როცა ერთ ფოტოზე 1 ადამიანია, მეორეზე კი — 4. ამისთვის დაიწერა სპეციალური collate_fn ფუნქცია.

5. რა არის თქვენი გადაწყვეტის ძლიერი და სუსტი მხარეები?

ძლიერი მხარეები:

მაღალი სიზუსტე (F1 = 0.9068, IoU = 0.8948) მცირე სასწავლო ნაკრების პირობებშიც კი.

ეფექტური ოპტიმიზაცია (ზომის 50%-იანი შემცირება ხარისხის დაკარგვის გარეშე).

მარტივი და მოსახერხებელი ვებ-ინტერფეისი Confidence ზღვრის დინამიკური კონტროლით.

სუსტი მხარეები (Error Analysis-ის მიხედვით):

როდესაც რამდენიმე ქვეითი მჭიდროდ დგას და ერთმანეთს ეფარება (Occlusion), მოდელს ზოგჯერ უჭირს მათი ცალ-ცალკე ჩარჩოებად გამიჯვნა ან IoU მცირდება.

მონაცემთა ნაკრები მოიცავს მხოლოდ დღის განათების საუნივერსიტეტო და ქუჩის კადრებს, ამიტომ ღამის ან რთული მეტეოროლოგიური პირობების ფოტოებზე სიზუსტე შეიძლება შემცირდეს.

6. რას გააუმჯობესებდით დამატებითი დროისა და რესურსების არსებობის შემთხვევაში?

მონაცემთა ნაკრების გამდიდრება უფრო მრავალფეროვანი საგზაო კადრებით (მაგ. BDD100K ქვენაკრებით), რომელიც მოიცავს ღამის, წვიმისა და შორი ხედის სცენებს.

აუგმენტაციების გაფართოება (Color Jitter, Random Crop, Scale) განათების მიმართ მდგრადობის გასაზრდელად.

Mask R-CNN არქიტექტურის დამატება, რათა ჩარჩოებთან ერთად მოდელმა ქვეითის ზუსტი პიქსელური კონტურიც (Instance Segmentation) გამოყოს.

ვიდეო ნაკადზე მუშაობისთვის ობიექტების ტრეკინგის (მაგ. ByteTrack / DeepSORT) ინტეგრაცია.

5. AI ინსტრუმენტების გამოყენების აღწერა

პროექტზე მუშაობისას AI ასისტენტი გამოყენებულ იქნა როგორც სასწავლო მენტორი და ტექნიკური დამხმარე ინსტრუმენტი შემდეგი მიზნებით:
